# 다른 프로젝트에서 사용할 AGENTS.md

Project-CSP의 커밋 형식을 바탕으로 만든 독립형 템플릿이다.
각 파일에 규칙 전체가 들어 있어 `Docs/CommitConvention.md` 등 다른 문서를 함께 복사할 필요가 없다.

## 선택과 적용

- `common/AGENTS.md`: 분야에 관계없이 사용할 공통 커밋 규칙.
- `web/AGENTS.md`: 웹에 맞춘 커밋 라벨과 웹 구현·검증 기준. 공통 커밋 형식을 포함한다.

원하는 버전 하나를 새 프로젝트 최상위 폴더에 `AGENTS.md`라는 이름으로 복사한다.
당장 웹 프로젝트를 만들 때는 `web/AGENTS.md`를 사용한다.
기존 `AGENTS.md`가 있다면 덮어쓰기 전에 내용을 확인하고 필요한 규칙을 합친다.
프로젝트별 실행 명령, 기술 스택, 디렉터리 규칙은 복사한 파일에 추가한다.
현재 Project-CSP 최상위 `AGENTS.md`와 게임 개발 지침은 변경하지 않는다.

## 원본에서 조정한 내용

- 이모지, 라벨 이름, 한국어 제목, `* ` 본문 형식은 유지했다.
- 공통용에서는 게임 전용 설명을 일반 개발 용어로 바꿨다.
- 웹용에서는 `Design`을 레이아웃·반응형·UX 개선으로, `Asset`을 웹 정적 리소스로 정의했다.
- `Fix`, `Design`, `Patch`의 해결 방법은 본문에 반드시 남기도록 명확히 했다.
- 원본의 영문 머지 예시 대신 한국어 50자 미만 제목을 사용해 제목 규칙을 일관되게 적용했다.
- 웹 구현 기준은 기존 프로젝트의 도구와 디자인을 우선하며 특정 프레임워크를 강제하지 않는다.

이 파일들은 독립 사본이다. 원본 커밋 컨벤션을 나중에 바꿔도 자동으로 동기화되지 않는다.
