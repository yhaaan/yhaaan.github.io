# 렌즈 노트

《The Art of Game Design》의 렌즈를 개인 학습용으로 정리하는 정적 웹앱입니다. 책의 본문이나 렌즈 문구는 포함하지 않으며, 1번부터 113번까지 빈 카드만 제공합니다.

## 주요 기능

- 렌즈 번호·제목·본문·키워드·개인 메모 검색
- 채워진 렌즈, 빈 렌즈, 즐겨찾기 필터
- 카드 편집과 브라우저 자동 저장
- JSON 백업 내보내기 및 병합/교체 가져오기
- 데스크톱·모바일 반응형 화면
- 서버와 데이터베이스가 필요 없는 GitHub Pages 정적 배포

## 사용하기

Node.js 22 이상이 필요합니다.

```bash
npm install
npm run dev
```

표시된 로컬 주소를 브라우저에서 연 뒤 원하는 번호의 카드를 선택해 내용을 입력합니다. 프로덕션 빌드와 검증은 다음 명령으로 실행합니다.

```bash
npm test
```

정적 결과물은 `dist/client`에 생성됩니다.

## 데이터와 백업

입력한 내용은 현재 브라우저의 `localStorage`에만 저장되며 외부 서버로 전송되지 않습니다. 브라우저 데이터 삭제, 다른 기기 사용, 저장소 이름 변경으로 사이트 주소가 바뀌면 기존 데이터가 보이지 않을 수 있습니다. 내용을 많이 입력한 뒤에는 화면의 **백업 내보내기**로 JSON 파일을 보관하세요.

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소의 `main` 브랜치에 푸시합니다.
2. 저장소의 **Settings → Pages → Build and deployment**에서 Source를 **GitHub Actions**로 선택합니다.
3. 포함된 `.github/workflows/deploy-pages.yml`이 사이트를 빌드하고 배포합니다.

사용자 사이트(`계정명.github.io`)와 프로젝트 사이트(`계정명.github.io/저장소명`)를 모두 지원하도록 경로가 자동 설정됩니다.
