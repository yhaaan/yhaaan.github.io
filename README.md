# 렌즈 노트

운영자가 공개한 기본 렌즈를 누구나 보고, 각자의 브라우저에서 자유롭게 추가·수정할 수 있는 정적 사이트입니다.

## 저장 방식

- 모든 방문자는 `data/lenses.json`에 들어 있는 운영자의 기본값으로 시작합니다.
- 방문자가 사이트에서 수정한 내용은 해당 브라우저의 `localStorage`에만 저장됩니다.
- 한 방문자의 수정은 운영자 원본이나 다른 방문자의 화면에 영향을 주지 않습니다.
- 시크릿 모드, 다른 브라우저, 다른 기기에는 자동으로 동기화되지 않습니다.
- **기본값 복원**을 누르면 브라우저 수정본을 지우고 운영자가 공개한 최신 기본값으로 돌아갑니다.

## 사이트에서 편집하기

1. 원하는 렌즈 카드의 **내용 보기 · 편집** 또는 **내용 추가**를 누릅니다.
2. 제목, 내용, 검색 키워드, 메모를 입력합니다.
3. **렌즈 저장**을 누릅니다.
4. 수정본은 현재 브라우저에 자동 저장됩니다.

즐겨찾기, 번호·키워드 검색, 작성 상태 필터도 사용할 수 있습니다. **백업하기**로 개인 수정본을 JSON으로 내려받고, **가져오기**로 다시 불러올 수 있습니다.

## 운영자 기본값 변경

운영자는 저장소의 **Actions → 렌즈 추가·수정 → Run workflow**에서 기본 렌즈를 변경할 수 있습니다. 변경이 배포되면 새 방문자는 그 내용을 기본값으로 봅니다.

이미 개인 수정본이 저장된 방문자는 자신의 브라우저 데이터가 우선 표시됩니다. 새 운영자 기본값을 다시 받으려면 사이트의 **기본값 복원**을 사용하면 됩니다.

## JSON 형식

```json
{
  "appId": "art-of-game-design-lens-notes",
  "schemaVersion": 1,
  "edition": 2,
  "language": "ko",
  "exportedAt": null,
  "lenses": [
    {
      "number": 1,
      "title": "렌즈 제목",
      "content": "내용",
      "keywords": ["선택", "피드백"],
      "notes": "보충 메모",
      "favorite": false,
      "updatedAt": null
    }
  ]
}
```

`lenses`에는 1번부터 113번까지 정확히 113개 항목이 있어야 합니다.

## GitHub Pages 설정

저장소의 **Settings → Pages → Build and deployment**에서 Source를 **GitHub Actions**로 선택합니다. `main` 브랜치가 변경되면 사이트가 자동 배포됩니다.
